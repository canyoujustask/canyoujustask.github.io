Metin ve formül

Neuron is a fixed stochastic law rendered as sound.
No data. No learning. No optimisation.

A single mathematical formula is executed in real time to produce an auditory structure. The system uses probabilistic mechanisms also found in machine-learning models, but it contains no data, no training, and no adaptation. All probabilities are explicitly defined and function as compositional constraints—density, recurrence, silence, and temporal balance.

The system runs as a closed loop. Nothing is learned, nothing is optimised.
Only the formula operates.

Sound is not generated from data, but by a law.

Ii,j = Ki,j · Bi,j
Bi,j ∼ Bernoulli(Pi)

Stotal = ∑i=1L ∑j=1Xᵢ Ii,j

𝔼[Stotal]
= ∑i=1L ∑j=1Xᵢ Ki,j Pi
= ∑i=1L Ki Pi

Pr(Stotal = 0)
= ∏i=1L ∏j=1Xᵢ (1 − Ki,j Pi)
= ∏i=1L (1 − Pi)Kᵢ
